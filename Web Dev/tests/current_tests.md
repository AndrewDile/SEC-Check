# Current tests

Generated by `python tools/document_tests.py` from a passing run of the test suite (84 tests, 0 skipped). Regenerate it after changing the tests.

Each test runs against two real local servers: the Web App and a fresh, empty mock Core API (see `tests/helpers.py`). For every test this file lists:

- the HTTP requests the test sends, in order: to the Web App (with the signed-in user, `X-User` header), or straight to the Core API (marked **Core API**), as the system's API test clients do;
- the response each request returned, which is the expected output because the run passed;
- in gateway tests, the Web App API requests the Core API generated from those Core API calls;
- the Core API calls the Web App made on the test's behalf;
- the test's assertions, copied from the source.

Every Web App response is checked against the Web App contract; every Core API response, and every Core API call the Web App makes, against the Core contract.

Placeholders: `<incident_id>` is a randomly generated 12-digit ID, `<now>` is the time of the request, `<local-url>` is a localhost address (the mock Core API, or a deliberately unreachable one). All paths start with `/webapp/v1` unless shown otherwise. Long values are shortened with `…`.
